# Ecommerce SQL Data Analysis

## Project Overview
This project demonstrates SQL-based data analysis using an ecommerce database. PostgreSQL was used to create, manipulate, and analyze structured ecommerce data.

## Dataset
The database contains four related tables:
- Customers
- Products
- Orders
- Order Items

## SQL Concepts Used
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- SUM()
- AVG()
- COUNT()
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- Multiple-table JOINs
- Subqueries
- Views
- Indexes
- EXPLAIN / query optimization

## Key Analysis
The queries retrieve and filter records, sort orders, calculate total and average sales, combine related tables, identify orders above average value, create a customer sales summary view, create indexes, and examine query execution plans.

## Tools Used
- PostgreSQL 18
- DB Fiddle
- SQL
- GitHub

## Conclusion
This project demonstrates how SQL can be used to query and analyze structured ecommerce data using filtering, sorting, aggregation, joins, subqueries, views, indexes, and query optimization.
